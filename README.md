# AI Stock

Streamlit 기반 국내 주식·ETF 추세 확인 앱입니다.  
진입점은 `index.py`이며, 상단 탭으로 **ETF 추세확인**(`ref_etf.py`)과 **개별 종목 분석**(`ref_stockanly.py`) 화면을 전환합니다.

---

## 실행 방법

```powershell
cd d:\myproject\stockai
py -m pip install -r requirements.txt
streamlit run index.py
```

선행 데이터(권장):

```powershell
py data\kospilist\kospilist_dataproc.py   # data/kospilist/kospilist.json 생성
```

---

## 전체 구조

```
index.py                 # 앱 셸: 탭·스타일·쿼리 네비게이션·페이지 라우팅
ref_etf.py               # ETF 추세확인 화면
ref_stockanly.py         # 개별 종목 분석 화면
data/kospilist/
  kospilist.json         # 종목·ETF·섹터 목록 (공통 입력)
  kospilist_dataproc.py  # 목록 생성
data/etf/                # 섹터별 사전 수집 그리드(배치용, UI는 yfinance 실시간 조회)
```

## 화면 구성

### 공통 셸 (`index.py`)

| 영역 | 내용 |
|------|------|
| 브랜드 | `AI Stock` |
| 탭 메뉴 | `ETF 추세확인` / `개별 종목 분석` |
| 레이아웃 | wide, 사이드바·기본 헤더 숨김 |
| 공통 데이터 | 세션 최초 진입 시 `kospilist.json` 캐시 재로드 |

기본 시작 탭은 **ETF 추세확인**입니다.

---

### 1) ETF 추세확인 (`ref_etf.py`)

섹터별 ETF 개수를 2열 그리드로 보여주고, 섹터·종목을 눌러 개별 분석으로 넘어갑니다.

#### 화면 요소

```
┌─────────────────────────────────────────────┐
│ AI Stock │ ETF 추세확인 │ 개별 종목 분석     │
├─────────────────────────────────────────────┤
│ 캡션: 섹터 N개 · ETF N개 · ...              │
│ ┌────────┬───┬────────┬───┐                 │
│ │ 섹터   │수 │ 섹터   │수 │                 │
│ │ 바이오 │21 │ 반도체 │.. │  ← 섹터 클릭    │
│ ├────────┴───┴────────┴───┤                 │
│ │ [펼침 행 · colspan 4]   │  ← 전체 한 줄   │
│ │ [칩] [칩] [칩] ...      │  ← ETF 종목명   │
│ └─────────────────────────┘                 │
└─────────────────────────────────────────────┘
```

| 조작 | 동작 |
|------|------|
| 섹터명 클릭 | 바로 아래 **전체 행(`colspan=4`)**에 해당 섹터 ETF 칩 목록 표시 |
| 다른 섹터 클릭 | 이전 펼침 닫고 새 섹터만 펼침 |
| ETF 칩 클릭 | 동일 창에서 **개별 종목 분석** 탭으로 이동 |

#### 데이터

- 입력: `data/kospilist/kospilist.json` (`ETF=Y` 종목, 섹터별 그룹)
- 표시: 섹터명, 종목 수, 종목명 칩 (`yahoosymbol`은 이동용 키)

---

### 2) 개별 종목 분석 (`ref_stockanly.py`)

종목을 고르면 Yahoo Finance로 시세를 받아 **150일 분석 그리드**와 **3개월 차트**를 보여줍니다.

#### 화면 요소

```
┌─────────────────────────────────────────────┐
│ AI Stock │ ETF 추세확인 │ 개별 종목 분석     │
├─────────────────────────────────────────────┤
│ [시장▼] [섹터▼] [종목 검색......] [검색]    │
│ 종목 목록 그리드 (행 선택)                  │
├─────────────────────────────────────────────┤
│ 종목명 (심볼)                               │
│ 현재가 / 시가총액 / PER                     │
│ 150일 분석 그리드 (+ CSV 다운로드)          │
│ 3개월 종가·거래량 차트                      │
│ 3개월 코스피·RS지수 차트                    │
│ 3개월 종가·이동평균(MA) 차트                │
└─────────────────────────────────────────────┘
```

| 영역 | 설명 |
|------|------|
| 필터 | 시장(`전체`/`KOSPI`/`KOSDAQ`/`ETF`), 섹터, 키워드 → **검색** 시 적용 |
| 종목 목록 | 행 클릭 시 `야후심볼`을 선택 심볼로 설정 |
| 메트릭 | 현재가·등락률, 시가총액, PER |
| 150일 그리드 | 날짜, 종가, 거래량, 코스피, RS지수, MA10~150 |
| 차트 | 최근 3개월 · 종가/거래량, 코스피·RS, 종가·MA |

#### 지표 의미

| 지표 | 계산 |
|------|------|
| RS지수 | `(종목 20일 수익률 / 코스피 20일 수익률) × 100` |
| MA | 종가 이동평균 (10/20/30/50/100/150) |
| 그리드 색 | 종가·거래량 전일 대비 상승=빨강, 하락=파랑 |

#### 데이터

- 목록: `kospilist.json`
- 시세: `yfinance` (종목 + 코스피 `^KS11`, period `1y`)

## 사용자 흐름

```
앱 시작 (index.py)
        │
        ▼
┌───────────────────┐
│ ETF 추세확인      │ ← 기본 탭
│ 섹터 그리드 표시  │
└─────────┬─────────┘
          │ 섹터 클릭 → ETF 칩 목록(전체 행)
          │ ETF 칩 클릭
          ▼
  URL 쿼리 설정 (동일 창)
  ?goto=stock&symbol=...&sector=...&keyword=...
          │
          ▼
  index.apply_query_navigation()
  · nav_page → 개별 종목 분석
  · symbol / 시장=ETF / 섹터 / 키워드 세션 반영
  · query_params 제거
          │
          ▼
┌───────────────────┐
│ 개별 종목 분석    │
│ 필터·목록 반영    │
│ 150일 그리드·차트 │
└───────────────────┘

직접 경로:
  상단 탭 「개별 종목 분석」
    → 시장/섹터/검색 → 목록 행 선택 → 동일 분석 화면
```

### ETF → 개별 분석 연동 상세

`ref_etf` 칩 클릭 시 쿼리 파라미터로 넘기고, `index.apply_query_navigation()`이 세션에 옮깁니다.

| 쿼리 | 세션/UI 반영 |
|------|----------------|
| `symbol` | `st.session_state["symbol"]` (분석 대상) |
| `goto=stock` | 탭을 `개별 종목 분석`으로 전환 |
| `sector` | 종목 목록 섹터 필터 |
| `keyword` | 종목 검색어 (없으면 심볼 코드부) |
| (고정) | 시장 필터 = `ETF` |

이후 목록에서 해당 ETF가 보이도록 필터가 맞춰지고, 선택 심볼로 그리드·차트가 로드됩니다.

## `index.py` 역할 요약

| 함수 | 역할 |
|------|------|
| `main()` | 페이지 설정 → 캐시/목록 로드 → 쿼리 네비 → 스타일 → 탭 렌더 → 페이지 분기 |
| `render_top_bar()` | 브랜드 + 탭 radio (`nav_page`) |
| `apply_query_navigation()` | ETF 칩 → 개별 분석 딥링크 처리 |
| `clear_caches_and_reload_stock_list()` | 세션당 1회 캐시 클리어 후 `kospilist` 재로드 |
| `inject_styles()` | 전역 폰트·탭·여백 CSS |

페이지 분기:

```python
if page == "ETF 추세확인":
    ref_etf.render_page()
elif page == "개별 종목 분석":
    ref_stockanly.render_page()
```
